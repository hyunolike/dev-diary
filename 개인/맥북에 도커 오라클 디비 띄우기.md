## 맥북에 도커 오라클 디비 띄우기 (feat. colima)
> 작성날짜: 25.07.13

### 요약
- Colima: colima는 macOS에서 Docker를 사용하기 위한 경량 가상화 환경

```
# 중지
colima stop

# 시작
colima start

ARM 맥(M1, M2) 사용하는 경우: 🔥
colima start --arch aarch64
```

### 도커 컴포즈 작성
```yml
version: "3.8"

services:
  oracle-db:
    image: gvenzl/oracle-xe:21-slim
    container_name: oracle-db
    ports:
      - "1521:1521"  # SQL*Net
      - "8080:8080"  # APEX (선택적)
    environment:
      - ORACLE_PASSWORD=oracle123   # 기본 SYSTEM/ORACLE 계정 비밀번호
      - APP_USER=appuser            # 사용자 계정명
      - APP_USER_PASSWORD=app123    # 사용자 계정 비밀번호
    volumes:
      - oracle_data:/opt/oracle/oradata

volumes:
  oracle_data:

```
